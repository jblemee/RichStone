Description
===========

Stone have a chance to drop iron and gold nugget! Enchanted tool with fortune will increase the drop rate.

Drop probability
----------------

| Fortune | Iron | Gold |
|---------|------|------|
|         | 11%  | 1%   |
| I       | 19%  | 3%   |
| II      | 31%  | 9%   |
| III     | 62%  | 28%  |

The probabilities can be easily customize by editing the `stone.json` file.

Installation
============

- Download Zip
- extract to the `datapacks` directory
- The directories should look like this: `datapacks/OreInStone/data`

More detailed instructions [here](https://minecraft.fandom.com/wiki/Tutorials/Installing_a_data_pack)

Compatibility
============

Minecraft 1.21
