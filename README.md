Description
===========

Stone have a chance to drop iron and gold nugget! Enchanted tool with fortune will increase the drop rate.

Drop probabilities
------------------

| Fortune | Iron | Gold |
|---------|------|------|
|         | 11%  | 1%   |
| I       | 19%  | 3%   |
| II      | 31%  | 9%   |
| III     | 62%  | 28%  |


Compatibility
============

Minecraft 1.21
